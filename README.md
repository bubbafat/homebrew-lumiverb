# Bubbafat Lumiverb

## How do I install these formulae?

`brew install bubbafat/lumiverb/<formula>`

Or `brew tap bubbafat/lumiverb` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "bubbafat/lumiverb"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
